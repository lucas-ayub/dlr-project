\chapter{Introduction}\label{ch:intro}

\section{Context}

A conventional SAR cannot have both a fine azimuth resolution (high PRF) and a wide swath (long interval between pulses). Multichannel systems break this trade-off by receiving each pulse
with several apertures displaced along track \cite{Krieger2004,Gebert2009}. Each channel is aliased, but together they
sample the azimuth signal at the full rate, and an \emph{azimuth reconstruction} (a filter bank) recovers the unambiguous
spectrum.

In multistatic formations the receivers sit on several platforms and the baselines are large
\cite{Sakar2020tgrs,Sakar2022thesis}. With a \emph{cross-track} baseline the bistatic range history depends on the
scatterer height; the filters assume $h_0=0$, so any other height leaves a channel-dependent phase and the aliased parts
no longer cancel.

Airborne motion compensation removes a similar height-dependent phase position by position from an external DEM
\cite{Prats2005topo,Prats2005thesis,Prats2007moco}. Here too the phase of each channel is known from the DEM and the
geometry; the question is how to use it in the reconstruction.

\section{Objective}

Remove the ambiguities caused by topography using \emph{only the system parameters and a DEM}, without knowing where the
scatterers are:
\begin{enumerate}
  \item How large are the ambiguities caused by unaccounted topography?
  \item How can the DEM be used inside the reconstruction so that the image reaches the quality of an unaliased reference?
\end{enumerate}
